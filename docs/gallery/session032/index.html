Verification and disclosure

Model code executed only in restricted, network-disabled evaluator realms with module allowlists and timeouts (Express routes via supertest, Python via a restricted subprocess, React behavior in a jsdom realm with failing fetch). The recycled sandbox has no Docker daemon, so this session runs the evaluator as local node/python subprocesses whose worker logic is byte-identical to the Session031 Docker image; the parity check against the Docker-verified Session031 record is re-validated live before this gallery is published. The static gallery serves the same model bytes with vendored React 18.3.1 UMD (docs/vendor/, sha-256 pinned); the evaluator itself runs React 19.1.1. The jsdom mount is a behavioral DOM check, not a real browser click test. The Express/Python half cannot run on static hosting; CI verifies it end-to-end and publishes the report JSON below.
