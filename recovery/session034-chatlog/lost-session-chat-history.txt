## 4. Main research hypothesis

Our current hypothesis is:

Certain internal computations may contribute to Qwen's ability to maintain programming contracts, track data structures, and select appropriate operations.

If those computations can be identified causally, carefully targeted modifications might improve specific coding behaviors.

However, those improvements must transfer beyond the examples used to construct the modifications.

Your job is to test this hypothesis, including the possibility that it is false.

A failed hypothesis is a valid research result when properly measured.

3. Validate syntax.
4. Run functional tests.
5. Record failures.
6. Identify the smallest relevant correction scope.
7. Provide Qwen with precise feedback.

Use a bounded candidate-search budget.
